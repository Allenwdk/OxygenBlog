# 画廊图片目录

画廊页面会自动扫描这个目录，**分类直接由文件夹结构决定**，不需要任何配置。

## 目录约定

```
public/gallery/
├── 壁纸/                ← 主分类「壁纸」
│   ├── a.png
│   └── 原神/            ← 子分类「原神」
│       └── Ayaka.png
└── 站点截图/             ← 主分类「站点截图」
    └── shot.png
```

- 一级文件夹 = 主分类，更深层的文件夹 = 子分类
- 直接放在 `public/gallery/` 根下的图片归入「未分类」
- 支持的格式：jpg / jpeg / png / gif / webp / avif（**不支持 svg**）
- 图片显示顺序即分类名与文件名的字典序

## 新增分类

直接建文件夹、把图片丢进去即可，页面会自动出现新的分类胶囊。不需要改任何代码。

## 注意

图片会在构建期被扫描并写进页面，因此**新增图片后需要重新构建/部署**才会出现在线上。
